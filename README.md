# Build/Run Instructions

# 1 - Prerequisites
- Python 3.10+
- An IDE (Optional)
# 2 - SETUP
1. From the IDE or Terminal/ Command Prompt copy and paste:
git clone https://github.com/stevenslcc2430/Programming-Project-1-Set-Operations

2. Move to the source folder with:
cd Programming-Project-1-Set-Operations/src

3. You are ready to run the program
# 3 - Run the Program
1. To run regular sets enter this command:
- python3 main.py --select set
2. To run multisets enter this command:
- python3 main.py --select bag 
- Tests can be found under "Verification & Test Cases.py"
- To run tests, type or copy into the terminal: python3 "Verification & Test Cases.py"
- (If succesfully ran there will be a lack of system output signifying no fails)
